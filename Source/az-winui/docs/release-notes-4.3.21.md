# Accessibility Zoom 4.3.21

- Removes the recurring six-hour GitHub update check. Automatic checks run once, about 10 seconds after launch, when enabled.
- Keeps on-demand checks in the Updates card and tray menu. The startup-check switch can be turned off without disabling manual checks.
- Clarifies the update setting and keeps confirmation before downloading, installing or restarting.
- Omits embedded debug symbols from release builds to avoid distributing local builder usernames and source paths.
- Expands the project page with setup instructions, feature explanations, default shortcuts and privacy details.

Existing settings, profiles, shortcuts and imported crosshairs are retained. Use **Updates > Check for updates** and then **Update and restart**, or download and run **AccessibilityZoom.App-win-Setup.exe**.
